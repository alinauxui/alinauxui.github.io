# Сайт-портфолио Алины Рысмендиевой

Сайт: https://alinauxui.github.io · репозиторий: `alinauxui/alinauxui.github.io` (GitHub Pages, ветка `main`, папка `/`).
Публикация: любой push в `main` → GitHub Pages сам пересобирает сайт за 1–2 минуты.

## Кто и зачем
- Алина Рысмендиева — UX/UI дизайнер из Бишкека, переход из архитектуры, интерьеров и SMM.
- Сайт нужен для поиска работы: стажировка или junior, любая сфера (сейчас интересен в том числе финтех), офис в Бишкеке или удалённо.
- Не делать акцент на нише «материнство / здоровье»: эти сферы — опыт, а не ограничение.

## Структура файлов
- `index.html` — вся страница (Tailwind CDN 3.4.17, шрифты Plus Jakarta Sans + Cormorant Garamond italic из Google Fonts).
- `flex-carousel.js` — карусель кейсов; данные в `DEFAULT_ITEMS` (обложка, подписи, описание, ссылка на Behance).
- `scroll-expand-media.js` — анимация блока «Обо мне»; `experience-section.js` — горизонтальная лента «Мой путь».
- `assets/` — портрет, логотипы (`logo-dark.png`, `logo-light.png`), фоны; `cases/` — обложки кейсов 1600×900.
- `README.md` и `LICENSE` — указание на шаблон ECHO by Jishnu Mondal (MIT). Не удалять: этого требует лицензия. На самом сайте упоминания шаблона нет — так и оставить.

## Как вносить правки
1. Отредактировать `index.html` / `flex-carousel.js` / файлы в `assets/`, `cases/`.
2. Проверить вёрстку на ширине 1440 и 390 px.
3. Commit + push в `main`. Через 1–2 минуты проверить https://alinauxui.github.io.
